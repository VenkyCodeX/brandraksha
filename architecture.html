Detection & Scoring Logic
Module Key Signals Risk Thresholds Official Exclusion
Social Username Levenshtein similarity (+15–50) · lookalike chars · role-word (+reason) · payment (+30) · credential (+40) LOW <30 · MED 30–59 · HIGH 60–79 · CRIT ≥80 Normalized exact match → OFFICIAL_MATCH
Domain Hostname Damerau-Levenshtein sim (+10–45) · lookalike chars · added brand word (+10) · TLD-only diff = 0 pts LOW <30 · MED 30–54 · HIGH 55–74 · CRIT ≥75 Exact domain or subdomain → OFFICIAL_MATCH
App Store (Apple & GP) Name similarity (+10–40) · diff bundle ID (+25) · diff publisher (+20) · brand in description (+10) · logo hash sim (+15 if ≥70%) Threshold ≥20 · LOW <30 · MED 30–59 · HIGH 60–79 · CRIT ≥80 Bundle ID / track ID / name+publisher → excluded
